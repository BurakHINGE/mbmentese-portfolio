# Web Sitesi Ana Sayfa Bilgileri

Bu web sitesi, Mehmet Burak Menteşe'nin kişisel portfolyosu ve teknik blogudur.
Site tamamen 'Vanilla' (saf) HTML, CSS ve JavaScript kullanılarak sıfırdan inşa edilmiştir. React veya Angular gibi ağır frameworkler kullanılmamıştır.
Sitede dinamik bir çift dilli (Türkçe/İngilizce) çeviri motoru bulunmaktadır.
Modern cyberpunk ve glassmorphism tasarım dilleri kullanılmıştır. Hızlı yüklenmesi ve güvenliği için Cloudflare CDN üzerinden yayınlanmaktadır.

Ziyaretçiler ana sayfada güncel GitHub katkı (contribution) grafiğini görebilir ve öne çıkan projelere/blog yazılarına hızlıca ulaşabilir.
