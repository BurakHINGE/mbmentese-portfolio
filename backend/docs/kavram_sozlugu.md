# Sitedeki Kavramlar Sözlüğü (Glossary)

- RAG (Retrieval-Augmented Generation): Yapay zeka modellerinin, kullanıcının kendi veritabanında arama yapıp (Retrieve), bu bilgiyi kullanarak (Augment) yeni cevaplar üretmesi (Generate).
- Vanilla JavaScript / Vanilla CSS: React, Tailwind veya Bootstrap gibi hazır dış kütüphaneler (frameworkler) kullanmadan tamamen düz ve yalın kodla yazılım yapılması.
- Halüsinasyon (Hallucination): Yapay zekanın cevabını bilmediği bir soruya oldukça özgüvenli ve ikna edici bir şekilde yalan/uydurma cevaplar üretmesidir.
- Çift Dilli Çeviri Motoru (i18n): Sitede bulunan Türkçe-İngilizce değiştirme butonunun, sayfayı yenilemeden tüm metinleri özel JavaScript algoritması ile anında çevirmesi sistemi.
- JavaFX: Java ile modern masaüstü uygulamaları (GUI) geliştirmek için kullanılan gelişmiş bir görsel kütüphane.
- JSON Kalıcılığı (JSON Persistence): Kütüphane projesindeki verilerin (kullanıcılar, kitaplar) elektrik kesildiğinde bile kaybolmaması için basit bir veritabanı gibi JSON dosyasında tutulması işlemi.
- Clean URL: Sitedeki yönlendirmelerin sonundaki '.html' uzantılarının kaldırılarak ('mburakmentese.dev/hakkimda' gibi) daha temiz ve estetik görünmesi durumu.
- Schema Markup & Canonical: Arama motoru robotlarının (Googlebot vb.) sitenin mimarisini ve kime ait olduğunu çok daha hızlı anlaması için kod içine gömülen özel SEO sinyalleridir.
