# Proje: GhostHunter INC. (Siber Güvenlik)

Siber güvenlik analizleri, ağ (network) trafiği dinleme (sniffing) ve tehdit avcılığı konseptleri etrafında geliştirilmiş güvenlik aracı/projesi.
Sistem güvenliğini tehdit eden unsurları tespit etmek için C dili veya benzer düşük seviyeli araçlar kullanılarak sistem kaynaklarının taranması odaklıdır.
