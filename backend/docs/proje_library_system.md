# Proje: Kütüphane Yönetim Sistemi (Library Management System)

Kişisel kitaplık (raf) yönetimini ortak kütüphane, kopya takibi, ödünç alma mekanizması ve admin paneliyle harmanlayan JavaFX tabanlı modern bir masaüstü (GUI) uygulamasıdır.
Proje ilk aşamada konsol (terminal) tabanlı olarak başlamış, sonrasında büyük bir güncellemeyle şık bir JavaFX arayüzüne taşınmıştır.

Öne Çıkan Özellikler:
- Nesne Yönelimli Programlama (OOP): Sıkı sorumluluk ayrımı.
- Hibrit Raf Sistemi: Kişisel kitaplar ile kütüphaneden ödünç alınanların bir arada yönetimi.
- JSON Kalıcılığı: Harici sunucu veya SQL gerektirmeden json.jar kütüphanesi ile verilerin güvenle diske kaydedilmesi.
- Gelişmiş GUI: Tablolar (TableView) ve dinamik arayüz elemanları.
- Exception Handling (Hata Yönetimi): Kullanıcı hatalarına karşı programın çökmesini engelleyen güvenli mimari.
