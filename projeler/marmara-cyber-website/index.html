Çıkış Noktası ve Kapsam Starting Point and Scope

Marmara Cyber, kulübün kurumsal kimliğini yansıtmak, etkinlikleri duyurmak ve öğrencilere siber güvenlik alanında rehberlik etmek amacıyla hayata geçirildi. Tasarım aşamasında klasik şablonlardan kaçınılarak tamamen siberpunk ve terminal estetiğine odaklanıldı. Ziyaretçilerin siteyi hem Türkçe hem İngilizce deneyimleyebilmesi için harici kütüphane kullanmadan tamamen saf JavaScript ile dinamik bir çeviri altyapısı kuruldu.

Marmara Cyber was launched to reflect the club's corporate identity, announce events, and guide students in the field of cyber security. During the design phase, classic templates were avoided, focusing entirely on cyberpunk and terminal aesthetics. To allow visitors to experience the site in both Turkish and English, a dynamic translation infrastructure was built entirely with vanilla JavaScript without using external libraries.

Mimari Kararlar ve Zorluklar Architectural Decisions & Challenges

  • Saf JavaScript ile Dil Yönetimi: React veya Vue gibi büyük frameworkler yerine projenin hızlı yüklenmesi ve statik barındırmaya tam uyum sağlaması için tüm çoklu dil altyapısı vanilla JavaScript sözlük objeleriyle optimize edildi.
  • Responsive Tasarım Dengesi: Fütüristik cam efekti ve hiyerarşik yönetim kartlarının mobil cihazlarda bozulmadan dikey akışa geçmesi için CSS Grid ve Flexbox kombinasyonları titizlikle ayarlandı.
  • Language Management with Vanilla JS: Instead of large frameworks like React or Vue, the entire multi-language infrastructure was optimized with vanilla JavaScript dictionary objects to ensure fast loading and full compatibility with static hosting.
  • Responsive Design Balance: CSS Grid and Flexbox combinations were meticulously adjusted so the futuristic glassmorphism effect and hierarchical management cards transition flawlessly into a vertical flow on mobile devices.
